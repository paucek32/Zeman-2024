Option 3 carousel image folders

Drop images into these folders to control the image carousels after the site is rebuilt.
Supported file types: .jpg, .jpeg, .png, .webp, .avif, .gif

Folders:
- home
  Homepage photo-strip carousel after the hero.

- about
  Homepage About Zeman rotating image stack.

- services/custom-workholding
- services/aerospace-tooling
- services/foundry-tooling
- services/precision-manufactured-parts
- services/built-to-print-tooling
- services/custom-manufacturing
  Photo-strip carousel on each matching service page.

Images sort by filename, so prefix names with numbers if you want a specific order:
01-shop-floor.jpg
02-machine-detail.jpg
03-finished-part.jpg

If a folder is empty, Option 3 keeps using its current fallback images.
